# Plan: OpDesk SP — Linux SIP Softphone (Qt6 + baresdk)

## Overview

Build a modern desktop SIP softphone (Zoiper-like) for Linux using:

- **baresdk.a** — pre-built static archive (baresip + libre + librem) at `~/bare/baresdk/dist/linux/x86_64/`
- **Qt6** — same toolkit as Zoiper and Linphone; supports static linking for self-contained binary
- **SQLite amalgamation** — `sqlite3.c` + `sqlite3.h` embedded in source tree (no system libsqlite3 dep)

**Target directory:** `~/bare/opdesk/` (sibling to `baresdk/`)

Goal: one executable, minimal runtime dependencies.

---

## Static Dependency Strategy

| Dependency | How resolved |
|---|---|
| baresdk.a | Already static — link directly |
| Qt6 | System Qt6 for dev (`qt6-base-dev`); static Qt6 for release (vcpkg or build from source) |
| SQLite3 | Embed `sqlite3.c` + `sqlite3.h` amalgamation in `third_party/sqlite/` |
| OpenSSL | Static: `-l:libssl.a -l:libcrypto.a` |
| pthreads, zlib, libm, libdl, libresolv | System — always present |

## Thread Model (critical)

```
Main thread:  QApplication::exec()  ←→  Qt signals/slots
Libre thread: re_main()             ←→  re_thread_async() + callbacks

Qt → libre:  re_thread_async(work_h, cb_h, arg)
             work_h runs on libre thread, cb_h called on libre thread when done

libre → Qt:  Inside baresip event callbacks, call:
             QMetaObject::invokeMethod(obj, [this] { emit signal(...); }, Qt::QueuedConnection)
             Safely crosses thread boundary to Qt main thread
```

**Verified API signatures** (from `re_main.h` / `re_async.h`):
```c
typedef int  (re_async_work_h)(void *arg);   // returns int
typedef void (re_async_h)(int err, void *arg);

int re_thread_async(re_async_work_h *work, re_async_h *cb, void *arg);
int re_thread_async_init(uint16_t workers);  // call once before re_main
```

## Phase 2: Core Engine

### 5. `app.h / app.cpp` — OpDeskApp

```
class OpDeskApp {
public:
    OpDeskApp();
    ~OpDeskApp();     // ua_stop_all → ua_close → baresip_close → libre_close
    void start();     // spawns libre_thread_ running re_main()
    void stop();      // re_cancel() then join

private:
    std::thread libre_thread_;
    static void bevent_handler(enum bevent_ev, struct bevent *, void *arg);
};
```

Init sequence (verified against baresip.h):
1. `libre_init()`
2. `conf_configure_buf(default_cfg_buf, len)` — sensible defaults from in-memory config
3. `re_thread_async_init(4)` — async workers for thread bridging
4. `baresip_init(conf_config())`
5. `ua_init("OpDesk SP v1.0", true, true, true)` — enable UDP, TCP, TLS
6. `module_preload()` for: `opus`, `g711`, `g722`, `plc`, `srtp`, `dtls_srtp`, `stun`, `turn`, `ice`, `pulse` (fallback: `alsa` or `pipewire`)
7. `bevent_register(bevent_handler, this)`
8. Launch `libre_thread_` running `re_main(nullptr)`

Shutdown: `re_cancel()` → join thread → `ua_close()` → `module_app_unload()` → `baresip_close()` → `re_thread_async_close()` → `libre_close()`

struct CallStatsData {

    uint32_t tx_packets_sent, rx_packets_sent;
    int tx_packets_lost, rx_packets_lost;
    uint32_t tx_jitter_us, rx_jitter_us;  // µs

    double tx_avg_bitrate, rx_avg_bitrate;
    uint32_t tx_bytes, rx_bytes;
    uint32_t tx_packets, rx_packets;

    // From stream_jbuf_stats()

    uint32_t jb_lost, jb_late, jb_oos, jb_overflow;

    // Computed
    double tx_loss_pct, rx_loss_pct;

class CallStats : public QObject {
    Q_OBJECT

- `stream_metric_get_tx_n_packets()` / `stream_metric_get_rx_n_packets()`

### 25. Thread Bridging Details

**Qt → libre** (calling baresip functions from UI thread):
```cpp
void SipEngine::dial(const QString &account_id, const QString &uri) {
    auto *ua = accounts_->getAccount(account_id)->ua();
    QByteArray uriBytes = uri.toUtf8();
    // Post to libre thread:
    re_thread_async(
        [](void *arg) -> int {  // work function on libre thread
            auto *d = static_cast<DialData*>(arg);
            struct call *call = nullptr;
            ua_connect(d->ua, &call, nullptr, d->uri, VIDMODE_OFF);
            delete d;
            return 0;
        },
        nullptr,  // no callback needed
        new DialData{ua, uriBytes.constData()}
    );
}
```

**libre → Qt** (baresip events to UI):
```cpp
static void bevent_handler(enum bevent_ev ev, struct bevent *event, void *arg) {
    auto *engine = static_cast<SipEngine*>(arg);
    if (ev == BEVENT_CALL_ESTABLISHED) {
        struct call *call = bevent_get_call(event);
        CallInfo info = extractCallInfo(call);
        // Safely cross to Qt thread:
        QMetaObject::invokeMethod(engine, [engine, info]() {
            emit engine->callEstablished(info);
        }, Qt::QueuedConnection);
    }
    else if (ev == BEVENT_VU_TX) {
        double level = ...; // extract from event
        QMetaObject::invokeMethod(engine, [engine, level]() {
            emit engine->audioLevelTx(level);
        }, Qt::QueuedConnection);
    }
    // ... similar for all events
}
```

## Key API Mappings (all verified against headers)

| Feature | baresip API |
|---|---|
| Init | `libre_init()`, `conf_configure_buf()`, `baresip_init()`, `ua_init()` |
| Config from memory | `conf_configure_buf(buf, len)` |
| Module load | `module_preload("opus")` etc. |
| Thread bridge | `re_thread_async_init(4)`, `re_thread_async(work, cb, arg)` |
| Account alloc | `ua_alloc(&ua, "sip:ext@domain")` |
| Auth | `account_set_auth_user()`, `account_set_auth_pass()` |
| Multiple accounts | Multiple `ua_alloc()` calls — each is independent UA |
| Registration | `ua_register()`, `BEVENT_REGISTER_OK/FAIL` |
| Transport | `uag_enable_transport()`, `config.sip.transp` |
| STUN/TURN | `account_set_stun_uri()`, `account_set_stun_host/user/pass()` |
| ICE/NAT | `account_set_medianat("ice")` or `"turn"` |
| Dial | `ua_connect(ua, &call, nullptr, uri, VIDMODE_OFF)` |
| Answer | `ua_answer(ua, call, VIDMODE_OFF)` |
| Hangup | `ua_hangup(ua, call, 0, nullptr)` |
| Hold | `call_hold(call, bool)` |
| Transfer | `call_transfer(call, target)` |
| DTMF | `call_send_digit(call, key)` |
| Events | `bevent_register()`, `BEVENT_CALL_*`, `BEVENT_REGISTER_*`, `BEVENT_VU_*` |
| Call info | `call_peeruri()`, `call_peername()`, `call_duration()`, `call_id()`, `call_transp()` |
| Mic mute | `audio_mute(call_audio(call), bool)`, `audio_ismuted()` |
| Speaker mute | `audio_set_player(call_audio(call), "aubridge", "dummy")` to disable / restore |
| Audio levels | `BEVENT_VU_TX` / `BEVENT_VU_RX`, `audio_level_get()` |
| RTCP stats | `stream_rtcp_stats(audio_strm(call_audio(call)))` → `rtcp_stats` |
| Bitrate | `stream_metric_get_tx/rx_bitrate()`, `stream_metric_get_tx/rx_avg_bitrate()` |
| Packet counts | `stream_metric_get_tx/rx_n_packets()`, `stream_metric_get_tx/rx_n_bytes()` |
| Packet loss | `rtcp_stats.tx.lost`, `rtcp_stats.rx.lost` |
| Jitter | `rtcp_stats.tx.jit` (µs), `rtcp_stats.rx.jit` (µs) |
| RTT | `rtcp_stats.rtt` (µs) |
| Jitter buffer | `stream_jbuf_stats()` → `jbuf_stat` |
| Current codec | `audio_codec(call_audio(call), true/false)` |
| Audio devices | `baresip_ausrcl()`, `baresip_auplayl()` |
| Codecs | `baresip_aucodecl()`, `account_set_audio_codecs()` |
| Shutdown | `re_cancel()`, `ua_stop_all()`, `ua_close()`, `baresip_close()`, `re_thread_async_close()`, `libre_close()` |
